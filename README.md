# NTC Intern Management System

## Project Overview

The **NTC Intern Management System** is a professional Android application developed to streamline and manage the complete workflow of interns within an organization.

The application was developed according to the **requirements and specifications provided by the organization**, with the goal of making intern management more organized, efficient, and transparent.

The system provides separate functionalities for **Supervisors and Interns**, allowing tasks to be assigned, tracked, updated, completed, reviewed, and managed through a centralized mobile application.

## Key Features

### Supervisor Module

* Secure Supervisor Login
* Create and assign tasks to interns
* Select interns from registered users
* Set task deadlines
* Add task descriptions and requirements
* Monitor assigned tasks
* View task completion status
* Review completed tasks
* Approve or reject submitted tasks
* Provide feedback to interns
* Monitor intern progress

### Intern Module

* Secure Intern Registration and Login
* View assigned tasks
* View task descriptions and deadlines
* Start assigned tasks
* Update task progress
* Mark tasks as completed
* Submit completed tasks for supervisor review
* View supervisor feedback

## Technology Stack

* **Platform:** Android
* **Programming Language:** Kotlin
* **Database:** SQLite
* **Development Environment:** Android Studio
* **UI:** XML
* **Architecture:** Activity-based Android application
* **Version Control:** Git & GitHub

## Database

The application uses a local **SQLite database** to manage application data, including:

* User accounts
* User roles
* Intern information
* Task assignments
* Task deadlines
* Task status
* Supervisor feedback

The database is designed to maintain organized records of interns and their assigned tasks.

## Workflow

**Supervisor → Creates Task → Selects Intern → Sets Deadline → Assigns Task**

**Intern → Views Task → Starts Task → Completes Task → Submits Task**

**Supervisor → Reviews Task → Approves/Rejects → Provides Feedback**

## Project Objective

The primary objective of the system is to provide an efficient digital solution for managing interns and their assigned responsibilities.

Instead of relying on manual task assignment and progress tracking, the application provides a centralized platform where supervisors can manage intern activities and interns can easily access and update their assigned work.

## Development Approach

The application was developed based on the **functional requirements and workflow specified by the organization**. The system was designed with a focus on simplicity, reliability, ease of use, and efficient task management.

The application can be further extended with features such as notifications, online synchronization, attendance management, reports, analytics, and cloud-based data storage.
